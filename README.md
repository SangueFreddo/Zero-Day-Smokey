# 🛡️ Chi siamo

**Zero-day Smokey** è un team che si occupa di **sicurezza informatica**, con un approccio orientato al **Blue Team** e alla difesa dei sistemi informatici.

Ci concentriamo sulla sicurezza delle reti, sull'analisi dei sistemi, sul rilevamento delle minacce e sullo sviluppo di strumenti utili a migliorare la sicurezza e la visibilità degli ambienti digitali.

Il nostro obiettivo è sviluppare strumenti pratici, accessibili ed efficaci, rivolti agli appassionati di cybersecurity, ai ricercatori e ai professionisti del settore.

Crediamo nella formazione continua, nella collaborazione open source e in un approccio proattivo alla sicurezza informatica.

### 🔍 Le nostre aree di interesse

- 🛡️ **Blue Team Operations** — sicurezza difensiva, monitoraggio e rilevamento delle minacce.
- 🌐 **Sicurezza di rete** — individuazione degli host e analisi delle reti.
- 🔎 **Ricerca sulla sicurezza** — studio delle vulnerabilità e delle superfici di attacco.
- 💻 **Sviluppo di strumenti** — creazione di utility per le attività di cybersecurity.
- ⚙️ **Automazione** — semplificazione delle operazioni di analisi e sicurezza.

# 🚀 I nostri progetti

Il nostro progetto più conosciuto è **Zmap**, uno strumento pensato per rendere più semplice e immediato l'avvio delle operazioni di analisi di rete.

Puntiamo a realizzare strumenti intuitivi, pratici e utili per l'apprendimento e le attività di sicurezza difensiva.

## ⚡ Avvio rapido

Per avviare Zmap dal terminale, utilizza il seguente comando:

```bash
python Zmap.sh
```

Assicurati di avere Python installato e di eseguire il comando dalla cartella contenente i file del progetto.

> **Nota:** il comando presuppone che `Zmap.sh` sia uno script compatibile con Python. Se si tratta di un normale script Bash, il comando corretto sarà generalmente `bash Zmap.sh`.
